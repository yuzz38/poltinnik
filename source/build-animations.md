# Исходники анимаций

`animations-entry.js` подключает оригинальные модули motion, word-highlight и photo-chapters из design-taste-frontend. Они сохранены в `vendor/` без изменения. `assets/animations.js` уже собран в обычный IIFE-скрипт; браузер не делает модульные запросы, поэтому страница работает при открытии `index.html` через `file://`.

Для использования сайта ничего собирать не нужно. Если разработчик меняет исходники анимаций, пересобрать из корня проекта:

```powershell
npx --yes esbuild source/animations-entry.js --bundle --format=iife --target=es2018 --outfile=assets/animations.js --charset=utf8
```

Остальное поведение находится в обычном `assets/app.js`; стили страницы — `assets/styles.css`. Код главной HTML-страницы и CSS/JS не минифицирован.

В `assets-provenance.json` перечислены исходные фотографии и таймкоды кадров из видео. Все фотографии и видеоматериалы взяты из папки заказчика, сторонние стоковые материалы и сгенерированные изображения не используются.

Кадры видео служат раскадровкой, а не автоматически создаваемыми макетами фигурок по загруженным фотографиям.
